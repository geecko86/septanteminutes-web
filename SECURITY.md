# Security Policy

Report security vulnerabilities to [contact@septanteminutes.be](mailto:contact@septanteminutes.be). Please do not open public GitHub issues for security reports. We aim to acknowledge within 7 days.

## Scope

In scope: this repository and the site it builds — the static export, the
GitHub Actions workflows, and the build and transcription scripts. Anything
that could expose a credential, change what gets deployed to
[septanteminutes.be](https://www.septanteminutes.be), or run code in CI is
worth reporting.

Out of scope: the podcast's editorial content, and the third-party platforms
the site links to or embeds (Spotify, Apple Podcasts, YouTube, the RSS host) —
report those to the platform concerned. Reports consisting only of automated
scanner output, or of a missing hardening header with no described impact, are
unlikely to get a detailed reply.

This is a personal project with no bug bounty. Credit is offered gladly to
anyone who wants it.
